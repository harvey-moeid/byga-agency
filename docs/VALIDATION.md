Tes kontrak OAuth/publish memakai Worker runtime Miniflare, D1 dan R2 serta server API simulasi; jaringan keluar nyata dinonaktifkan. Simulasi menguji perilaku kode, bukan bukti kompatibilitas/approval aplikasi TikTok pengguna. Research dan analytics memiliki tes parsing/aturan rekomendasi; pengambilan provider nyata belum diuji. Drag mouse native juga lolos pada viewport 1440×1600 ketika sumber dan target terlihat. Drag lintas area scroll pertama tidak memindahkan item; dukungan touch/auto-scroll masih perlu pengujian perangkat target. Refresh/revoke token, pagination penelitian dan delivery notifikasi perlu verifikasi akun/provider ketika kredensial tersedia.

Chromium sistem digunakan karena unduhan browser Playwright diblokir jaringan. Dokumentasi TikTok sempat diblokir proxy; domain yang diperlukan telah ditambahkan ke draft, tetapi menyimpan draft tidak mengubah runtime atau membuktikan akses berhasil. Tidak ada pengujian produksi Cloudflare, webhook/provider AI nyata, akun TikTok nyata, perangkat mobile fisik. Lima avatar pihak ketiga kini dibundel dan dimuat/dirender dalam browser; lisensi, checksum dan animasi diverifikasi.
