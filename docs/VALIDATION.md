Tes Worker menggunakan Miniflare dengan D1/R2 dan respons provider simulasi; seluruh jaringan keluar nyata dinonaktifkan oleh fetch mock. Tes browser mode live juga memakai respons API simulasi. Ini membuktikan kontrak dan perilaku kode yang diuji, bukan approval/kompatibilitas aplikasi TikTok pengguna atau keberhasilan provider nyata.

Smoke test menggunakan `.wrangler/verification-state` serta konfigurasi lokal dan credential uji terpisah. Tidak menggunakan credential provider pengguna. API lokal memperlihatkan status `blocked` untuk pekerjaan tanpa koneksi/final approval, bukan publish sukses. Migrasi additive terbaru tidak menghapus konten atau file pengguna.

Rendering software sempat membuat pemeriksaan animasi terlambat. Perpindahan avatar kini diintegrasikan dalam langkah kecil, dan mode 3D ringan aktif otomatis pada mobile/renderer software: DPR 0,75 tanpa shadow. Tes browser membaca quaternion tulang lutut Nova dari scene untuk membuktikan gerak dan pause, bukan hanya label status. Batas waktu startup/response 3D di tes disesuaikan dengan renderer software; perangkat fisik belum diukur.

Kalender drag/drop desktop dan form jadwal mobile telah diuji. Drag native melalui sentuhan dan auto-scroll lintas area belum diklaim tervalidasi. Furnitur tetap prosedural; avatar manusia siap pakai memiliki lisensi, checksum, tekstur dan clip yang telah diverifikasi. Screenshot `office-avatars*.png` mendokumentasikan tampilan avatar sebelumnya, sedangkan `workspace.png`/`mobile.png` merupakan tampilan tahap awal.

Receipt cron disimpan 30 hari, sehingga occurrence yang sudah dimulai tidak diulang otomatis. Kegagalan dicatat dan antrean dapat dilanjutkan pada occurrence berikutnya. Lease notifikasi mencegah pengiriman paralel; timeout/crash setelah provider menerima pesan masih dapat menghasilkan duplikat saat retry.

Pemeriksaan akhir `wrangler deploy --dry-run --outdir .wrangler/dry-run` juga lolos: paket Worker 1056,90 KiB (gzip 192,99 KiB), dengan bindings D1, R2, assets dan APP_URL yang sesuai. Tidak ada upload atau deployment produksi.

Deployment/domain produksi, provider AI nyata, aplikasi/akun TikTok nyata, Research API pengguna dan Discord/Telegram nyata belum diuji pada sesi ini. Lihat [STATUS.md](STATUS.md) dan [INTEGRATIONS.md](INTEGRATIONS.md) untuk implementasi dan syarat aktivasi.
